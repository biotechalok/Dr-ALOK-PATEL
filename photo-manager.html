Photo Manager

Use this tool on your computer. It prepares renamed JPG files and a new gallery entry. You still upload the files to GitHub; no password is needed here.

Publishing

  1. Upload the downloaded JPG to the main folder of your GitHub repository.
  2. For a new gallery photo, edit index.html and paste the downloaded snippet inside <div class="lab-grid"> before its closing tag.
  3. Commit changes and refresh your live site.
This is a local helper, not a connected CMS. It does not automatically publish to GitHub.
